Omni Referral Base

Multi-Level Referral Network & Commission Management

Build and manage a complete multi-tier referral network in Odoo 19. Track members, automate commission calculations, visualize your referral tree, and monitor performance through an interactive dashboard.

✨ Key Features

Multi-Level Commission Rules

Define commission percentages for each referral depth level. Supports unlimited levels with flexible rule configuration.

Referral Member Management

Complete member lifecycle management — Draft, Active, Suspended, Terminated — with sponsor hierarchy tracking.

Interactive Dashboard

Real-time KPI cards, commission trend charts, member growth charts, top members leaderboard, and pending commission approval — all in one view.

Referral Tree Visualization

Interactive expandable tree view to visualize the entire referral network for any member, with member status and commission balance.

Commission Withdrawal

Members can request commission withdrawals. Full approval workflow with balance tracking before and after withdrawal.

Member Card Report

Printable digital member card for each active member, complete with member code and contact details.

⚙️ How It Works

  1. Set up Commission Rules — Define percentage per level (Level 1, Level 2, etc.)
  2. Register Members — Create referral members linked to existing Odoo contacts
  3. Assign Sponsor — Connect each member to their sponsor to build the network
  4. Link to Sales Orders — Assign referral member to a sales order
  5. Track Commissions — Approve or reject commissions from the dashboard
  6. Process Withdrawals — Members submit withdrawal requests, manager approves
