# Omni Referral Base

Multi-Level Referral Network & Commission Management for Odoo 19

## Description

Omni Referral Base is a complete multi-level referral network and sales commission 
system for Odoo 19. It provides foundational structure for managing referral members, 
commissions, and withdrawals with intelligent gross profit-based commission calculation.

## Features

- Multi-level commission rules based on gross profit
- Referral member management
- Commission tracking and approval workflow
- Commission withdrawal management
- Interactive dashboard with charts
- Referral tree visualization
- Member card reports

## Installation

Install this module like any other Odoo module:

1. Copy the module folder to your Odoo addons directory
2. Restart Odoo server
3. Go to Apps, search for "Omni Referral Base"
4. Click Install

## Configuration

After installation:

1. Go to Referral > Configuration > Commission Rules
2. Define commission percentages per level
3. Configure settings via Settings > Referral
4. Create referral members and set sponsor hierarchy
